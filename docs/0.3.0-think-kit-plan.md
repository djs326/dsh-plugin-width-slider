# dsh-plugin-width-slider v0.3.0 收编规划（think-kit）

> 状态：M0 已批准（2026 会话）。分支：feat/0.3.0-think-kit。
> 决策均由用户逐项拍板确认，本文为执行契约；与代码不一致时以本文为准修订。

## 1. 目标

把开源插件 dsh-think-zh-expand（上游 baosfeng/my-dsh-plugins，MIT，v0.4.7）的能力
整体收编进 dsh-plugin-width-slider（本仓库，个人维护，npm 已发布）：

1. 思考/回复强制中文（host 端 systemPrompt 注入）
2. 思考块增强渲染（替换官方 assistant-step 渲染器；默认"思考中展开、思考完自动收起"）
3. 界面硬编码英文中文化（MutationObserver 精准替换）

并新增两个面向官方设置面板的 UI 补丁（F3/F4）。**所有功能全部做成独立开关**（默认开），
版本升至 0.3.0，保留包名 dsh-plugin-width-slider。

## 4. 官方设置面板 DOM 锚点（M0 校准结论）

来源：@deepseek-ai/dsh-client-ui-settings-general（本机 DSH Desktop checkout，
lib/client.js 未压缩 JSX）。结构（类名 hash 不稳定，仅作参考）：

```
div.overlay (role=presentation)
├── div.mask (aria-hidden, onClick close)
└── div.panel  role="dialog" aria-modal="true" aria-labelledby=<titleId>
    ├── nav                       ← F4 目标列
    │   ├── div.navTitle (id=<titleId>, settings.header slot 内容)
    │   └── div.navList           ← tab 列表（滚动目标容器）
    │       └── button.navCell ×N (aria-current, 每 section 一项)
    └── div.content
        ├── div.header (settings.action + close 按钮)
        └── div.options (overflow-y:auto) ← 右侧内容区 settings.section
```

补丁锚点策略（不依赖 hash 类名，失效即静默）：
- 弹窗本体：document.querySelector('div[role="dialog"][aria-modal="true"]')
  且其直接子元素含 <nav>（即设置面板，排除其它 dialog）。
- F4 滚动目标：dialog > nav 内首个含多个 button 的 div 子元素（=navList；
  实现 findNavList 以"含 button"判定，比固定第 2 个更抗标题区结构变化）；
  运行时探测后直接改 inline style（flex:1; min-height:0; overflow-y:auto），
  标题行不动。滚动条样式套官方变量
  (--dsh-scrollbar-thumb / --dsh-scrollbar-thumb-hover)。
- F3 调宽目标：同弹窗本体；覆盖内联 width 于 [640, min(1280, vw-48)]，
  挂右侧内边拖柄（绝对定位、cursor: ew-resize），拖动改 width，持久化
  localStorage（键 dsh.conversation.settingsPanelWidth）。
- 官方默认几何：panel width:800px; max-width:calc(100vw - 48px);
  height:min(800px, 100vh - 48px); border-radius:32px; overflow:hidden。
- 结构可能在 DSH 升级后变化；所有选择/修改都收敛到 settingsPanelPatch.ts
  内少数探测函数，探测失败安静跳过（无 console 噪音）。

行为差异注意：
- 上游 ThinkBlock：useState(true) 默认展开，open = expanded || running。
- 定制"自动收起"：useState(false) 初始收起；running 时为展开态；
  running 结束（running false）自动 setExpanded(false)；用户手动展开后，
  未再流式时不主动收起（下一次 running 结束再收起）。模式开关控制默认。
- registrant 用 dsh-plugin-width-slider；样式类名前缀实现为 dsh-ws-*
  （thinkView.tsx；避免与上游 dsh-think-zh-expand- 冲突），README 明示需
  卸载上游 dsh-think-zh-expand。

## 7b. 配置机制落地记录（M2 定案）

实现选用规划 §3 的**备选**方案（RPC + JSON 文件），原因：host 端官方
settings 文档 API 需依赖 settingsScope/schema 双端契约，学习与排错成本
高于插件所需（仅 7 个布尔/枚举开关）；open-with 的 RPC 模式已验证稳定。

- 存储：$DSH_HOME/storages/dsh-plugin-width-slider/settings.json（原子写
  tmp+rename）；默认值/合并逻辑 host 与 client 各持一份（config.ts 注释
  互相指向，改键须两端同步）。
- 协议：host inject ['systemPrompt','connection']，注册 /width-slider
  RPC（loopback 围栏）：readSettings / writeSettings。
- 热切换：client 总控页切换 → writeSettings（持久化）→ 本地 config store
  通知功能生命周期 sync；host 端 writeSettings 时对中文注入做热注销/注册。
- M3 的两个补丁开关（dialogResize/navScroll）字段已在 schema 中默认开，
  UI 与功能在 M3 接入。

  并 console 警告，不抛错。
