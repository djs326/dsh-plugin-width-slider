# dsh-plugin-width-slider v0.3.0 验证清单

> 用途：用户实机验证（M1-M3 功能）。前置：desktop profile 已同步构建产物，
> 需重启 DSH Desktop（host 端 index.mjs 与 client bundle 均生效）；已停用/
> 卸载上游 dsh-think-zh-expand；dsh-md-render 保持启用。

## A. 收编功能（M1）

- [ ] A1 思考块：新开一轮对话让模型思考，生成中思考块实时展开显示全文
- [ ] A2 生成结束后思考块自动收起为一行（思考图标 + 首行摘要）
- [ ] A3 点击收起的思考块可展开全文，再点可收起
- [ ] A4 思考内容里的代码块/表格/公式按 Markdown 渲染（非原始文本）
- [ ] A5 界面残留英文（如轨迹视图 Thinking / Tool Call）显示为中文
- [ ] A6 询问模型输出语言规则（可选）：应体现简体中文强制

## B. 总控页与开关（M2）

设置 → Width Slider · 对话宽度：

- [ ] B1 总控页分组可见：对话宽度滑块 / 思考块 / 输出语言 / 界面
- [ ] B2 关闭「宽度滑块」→ 滑块置灰禁用，官方原生拖拽手柄恢复可拖
- [ ] B3 关闭「思考块增强」→ 思考块回退官方单行折叠（需刷新重渲染该消息）
- [ ] B4 思考块模式切换「始终展开」→ 新生成思考块结束后保持展开
- [ ] B5 关闭「强制中文」→ 之后新会话不再注入中文规则（可问模型验证）
- [ ] B6 关闭「界面中文化」→ 英文标签不再被替换
- [ ] B7 任意开关切换后立即生效；重启 DSH 后开关状态保留

## C. 官方面板补丁（M3）

- [ ] C1 打开设置面板：弹窗右下角出现三角把手（悬停高亮）；顶部空白区悬停出现移动光标
- [ ] C2 拖动右下把手：弹窗宽度与高度同时实时变化（min 640×560），关闭再开尺寸被记住
- [ ] C3 拖动顶部空白区：弹窗整体移动（不越出视口），位置被记住；双击把手复位 800×800 居中
- [ ] C4 左侧 tab 列表条目多到超高时出现滚动条（可滚动查看下方条目）
- [ ] C5 关闭「弹窗窗口化」「tab 滚动」开关：当前弹窗立即还原官方（把手/移动失效、尺寸回默认）、tab 滚动条消失；再开立即生效

## D. 回归（原有宽度滑块功能）

- [ ] D1 按下滑块进入全屏预览，拖动实时调宽，松开/Esc 返回设置
- [ ] D2 跟随窗口宽度模式仍正常
- [ ] D3 升级后原生拖拽手柄仍被隐藏（未开宽度滑块开关时除外）
