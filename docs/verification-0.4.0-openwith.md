## E. Open With（v0.4.0 新增）

- [ ] E1 对话头部出现胶囊按钮（点击在当前会话目录启动；无 cwd 的会话点击仅提示并忽略）
- [ ] E2 左键点击主按钮：在当前会话目录启动当前项（默认 VS Code，打开对应目录）
- [ ] E3 右侧箭头打开菜单：预设 4 项（VS Code/终端/PowerShell/资源管理器）+ 自定义项；隐藏项不出现
- [ ] E4 菜单选择某项：立即启动并切换为当前项（按钮文字/图标更新）
- [ ] E5 设置 → 对话宽度 → 打开方式组：预设/自定义两组可见，支持组内拖拽排序
- [ ] E6 点击项卡片设当前（行内出现"当前项"标记）；隐藏/显示按钮生效并即时反映到胶囊菜单
- [ ] E7 添加自定义项（名称 + .exe 路径，直接启动不经 cmd）：保存后立即出现在列表与胶囊菜单；图标后台自动提取
- [ ] E8 编辑自定义项（改名/改路径）；路径变化后图标重新提取
- [ ] E9 删除自定义项：从列表与胶囊菜单移除；当前项被删时回落到第一项
- [ ] E10 重启 DSH 后：自定义项/排序/当前项/隐藏状态保留（$DSH_HOME/storages/dsh-open-with/settings.json）
- [ ] E14 头部按钮选择某项后，设置面板"当前项"徽标同步（同一 currentId）
- [ ] E11 停用官方 dsh-plugin-open-with 后无重复按钮/重复设置入口
- [ ] E12 关闭「头部打开按钮」开关：按钮消失；重新开启恢复
- [ ] E13 关闭「Open With 设置」开关：总控页中打开项管理区隐藏；已配置项仍生效
