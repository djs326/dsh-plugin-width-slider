# dsh-plugin-width-slider v0.5.0 会话删除验证清单

> 破坏性功能：请用临时会话测试（新建一个无用的会话再删除）。

## F. 会话删除（v0.5.0）

- [ ] F1 点击会话条目右侧 "⋯"：菜单末尾出现红色"删除会话"项（垃圾桶图标、样式与官方项一致、hover 灰底、无分隔线；项目行的 ⋯ 菜单不出现）
- [ ] F2 点击"删除会话"：弹确认框（明确"永久删除、不可恢复"），取消则无变化
- [ ] F3 确认后：该会话从列表消失（原地刷新），会话数据目录被删除
- [ ] F4 同名/fork 会话（标题带 (N)）：删除的一定是所点那一行（行级 id，非标题匹配，规避删错风险）
- [ ] F5 删除当前正在运行（对话中）的会话：能安全停止并删除（或提示无法停止时取消）；若删的是当前所在会话，列表离开该会话不残留空白/幽灵
- [ ] F6 关闭「会话删除」开关：⋯ 菜单不再出现删除项；再开恢复
- [ ] F7 重启 DSH 后：被删会话不复活
