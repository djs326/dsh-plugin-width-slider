# dsh-plugin-width-slider v0.5.0 会话删除验证清单

> 破坏性功能：请用临时会话测试（新建一个无用的会话再删除）。

## F. 会话删除（v0.5.0）

- [ ] F1 鼠标悬停会话条目：右侧出现垃圾桶删除按钮（在 "⋯" 操作按钮左侧）
- [ ] F2 点击删除：弹确认框（明确"永久删除、不可恢复"），取消则无变化
- [ ] F3 确认后：该会话从列表消失，会话数据目录被删除
- [ ] F4 同名会话：先弹出候选列表（显示标题+时间），选择后才进入确认
- [ ] F5 删除当前正在运行（对话中）的会话：能安全停止并删除（或提示无法停止时取消）
- [ ] F6 关闭「会话删除」开关：悬停不再出现删除按钮；再开恢复
- [ ] F7 重启 DSH 后：被删会话不复活
